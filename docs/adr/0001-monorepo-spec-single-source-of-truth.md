# 0001. Monorepo with spec/ as the single source of truth

Date: 2026-10-11
Status: Accepted

## Context and Problem Statement
Normative requirement from spec/SPEC.md and architecture design.

## Decision Outcome
Use a monorepo structure where spec/ is the single normative source of truth for all formulas and schemas.

## Consequences
- Positive: Clear normative grounding and exact alignment with specification.
- Negative: Requires formal RFC process to modify in future versions.
