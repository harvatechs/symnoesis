# 0010. Evidence tiers E0-E3 on every artifact

Date: 2026-10-11
Status: Accepted

## Context and Problem Statement
Normative requirement from spec/SPEC.md and architecture design.

## Decision Outcome
Every score, card, map, and index entry explicitly displays its evidence tier (E0 specified, E1 synthetic, E2 provisional, E3 validated).

## Consequences
- Positive: Clear normative grounding and exact alignment with specification.
- Negative: Requires formal RFC process to modify in future versions.
