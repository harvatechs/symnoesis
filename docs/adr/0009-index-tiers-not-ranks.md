# 0009. Index uses tiers, not ranks; critical events outside the ranking

Date: 2026-10-11
Status: Accepted

## Context and Problem Statement
Normative requirement from spec/SPEC.md and architecture design.

## Decision Outcome
Present evaluated systems in statistically distinguishable tiers rather than single linear ranks.

## Consequences
- Positive: Clear normative grounding and exact alignment with specification.
- Negative: Requires formal RFC process to modify in future versions.
