# 0007. No GraphQL, queues, or database servers in v0.1; REST API optional

Date: 2026-10-11
Status: Accepted

## Context and Problem Statement
Normative requirement from spec/SPEC.md and architecture design.

## Decision Outcome
Prioritize static site generation and client-side execution; avoid server infrastructure complexity.

## Consequences
- Positive: Clear normative grounding and exact alignment with specification.
- Negative: Requires formal RFC process to modify in future versions.
