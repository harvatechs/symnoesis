# 0012. Global 70/30 weights with RFC-only domain overrides

Date: 2026-10-11
Status: Proposed

## Context and Problem Statement
Normative requirement from spec/SPEC.md and architecture design.

## Decision Outcome
Enforce global 70/30 human/system weight ratio; domain-specific modifications require Scientific Advisory Board RFCs.

## Consequences
- Positive: Clear normative grounding and exact alignment with specification.
- Negative: Requires formal RFC process to modify in future versions.
