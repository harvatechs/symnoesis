# Symnoesis Documentation: Diátaxis Framework

This directory organizes Symnoesis technical documentation following the **Diátaxis** documentation architecture:

| Category | Purpose | Target Document |
|---|---|---|
| **Tutorial** | Learning-oriented walkthrough for beginners | [tutorial.md](./tutorial.md) |
| **How-To Guide** | Goal-oriented steps for specific developer tasks | [how-to.md](./how-to.md) |
| **Reference** | Information-oriented technical descriptions | [reference.md](./reference.md) |
| **Explanation** | Understanding-oriented discussions and background | [explanation.md](./explanation.md) |
