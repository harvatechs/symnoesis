# Responsible Disclosure Policy

**Status:** Proposed

## 1. Principles

When a benchmark run reveals a Critical-Harm Indicator (CHI-1 through CHI-7) event in an evaluated AI system, Symnoesis follows a strict coordinated disclosure protocol.

## 2. Notification Timeline

1. **Private Notice**: The system developer or vendor receives a confidential notification containing classifier logs and cryptographic run manifests.
2. **Embargo Period**: A default 45-day disclosure window is established to enable the vendor to deploy safeguards.
3. **Publication**: Following the embargo period, the verified event is published on the corresponding Symnoesis Card and Index entry.
4. **Active Harm Exception**: If an ongoing vulnerability presents imminent risk to human life, maintainers and the Ethics Review Board may expedite publication.

## 3. Right of Reply

System operators retain the right to submit an official vendor response (under 200 words), which will be permanently displayed alongside the published Card and audit report.
