# Symnoesis Roadmap

This roadmap documents the phases from initial design to potential international standardization.

| Phase | Description | Status | Evidence Tier Target | Completion Criteria |
|---|---|---|---|---|
| **Phase 0** | **Foundations & Architecture** | In Progress | E0 (Specified) | Monorepo structure, toolchains, initial gate passing, verified prior-art log. |
| **Phase 1** | **Specification as Code & Core Engines** | Not Started | E1 (Synthetic) | Pure Python reference implementation and TypeScript port passing 100% of golden vectors with exact parity. |
| **Phase 2** | **Synthetic Sweeps & Tooling** | Not Started | E1 (Synthetic) | Automated synthetic persona sweeps, exact MILP Minimal Failure Cover, and reproducibility check (`make repro`). |
| **Phase 3** | **Human Cohort Pilot & Calibration** | Planned | E2 (Provisional) | IRB/ethics approval obtained; pilot cohort ($N \approx 200–400$) across 4 and 12 weeks; empirical threshold calibration. |
| **Phase 4** | **Public Beta & Index Edition 1** | Planned | E2–E3 | Seated Scientific Advisory Board and Steering Council; disclosure windows executed; first multi-system Index published. |
| **Phase 5** | **Independent Replication & Certification Scheme** | Planned | E3 (Validated) | Independent audit protocol operational; test-retest reliability $\ge 0.75$; certification body seated. |
| **Phase 6** | **International Standardization** | Planned | E3 (Validated) | Submission to open standards consortium (e.g., ISO/IEC JTC 1/SC 42, IEEE). |

*Note: Phase 3 onwards requires institutional ethics approval, clinical oversight, and dedicated research grant funding.*
