# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `0.1.x` | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability:
1. Use GitHub's private vulnerability reporting feature on this repository.
2. Alternatively, send an encrypted report to the security contact designated in [`ORG_FACTS.yaml`](./ORG_FACTS.yaml).

We will acknowledge receipt within 48 hours and provide a substantive response and remediation timeline within 7 days.

## Scope

This security policy applies to the code, APIs, documentation, and web assets of the Symnoesis repository. Reports concerning model behavior or AI system risks fall under the responsible disclosure framework outlined in [`docs/governance/disclosure.md`](./docs/governance/disclosure.md).
