# Support

## Where to Get Help

- **Documentation**: Browse tutorials, guides, and specifications in [`docs/guides/`](./docs/guides/) or on the project documentation site.
- **Specification Inquiries**: Open an issue with the `spec-question` template.
- **Bug Reports**: Open an issue with the `bug` template.
- **Community Discussions**: Use GitHub Discussions for questions regarding dyadic state measurement and benchmark usage.

## Emergency / Crisis Notice

Symnoesis is a scientific measurement instrument and is **not** a clinical, crisis-support, or medical service. If you or someone you know is in distress, please consult local mental health services or visit [findahelpline.com](https://findahelpline.com).
